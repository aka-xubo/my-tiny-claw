# 欢迎来到 go-tiny-claw 项目工作区

## 架构说明
- 本项目采用 Go 语言编写，追求极致性能。
- 所有的 API 接口都必须返回 JSON 格式，且包含 `code` 和 `message` 字段。
- 所有的错误处理，必须返回中文报错信息，绝对禁止使用英文抛错。

## 禁忌事项
- 不允许删除根目录的任何文件。

## 其他 coding 原则
- 开始任何编码、修改或排查任务前，必须先读取工作区外部的 `AGENTS.md`。优先检查当前目录的上级目录（例如 `../AGENTS.md`），再按目录层级向上查找。
- 外部 `AGENTS.md` 作为通用协作和编码规范；本文件作为 `workspace` 的项目特定补充。规则发生冲突时，优先遵循路径更具体的规则；用户在当前任务中的明确要求始终优先。
- 外部 `AGENTS.md` 不存在或无法读取时，继续按照本文件执行，并在任务结果中说明未读取到外部规则。
- 读取外部规则后，编码、测试、提交和文档修改都必须同时满足外部规则与本文件的要求。
